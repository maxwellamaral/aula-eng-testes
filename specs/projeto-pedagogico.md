# Projeto pedagógico — informações disponíveis no repositório

## Contexto confirmado

- Disciplina: Verificação, Validação e Testes de Software (VVTS).
- Público: Bacharelado em Engenharia de Software do IFPB, Campus João Pessoa.
- Os materiais abordam qualidade de software, verificação, validação e testes.

## Decisões que exigem fonte do docente

Este repositório não define, de forma canônica, cronograma completo, ementa oficial, critérios de avaliação, pesos, prazos, política institucional de IA, regras de entrega ou composição de grupos. Essas decisões devem ser fornecidas ou aprovadas pelo docente antes de serem incluídas em uma aula, laboratório ou slide.
